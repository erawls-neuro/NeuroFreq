phaseamplitudecoupling/ README
——————————----------------------------------------------------------------
The phaseamplitudecoupling folder of NeuroFreq contains functions for 
calculating PAC. These functions implement ERPAC, Mean Vector Length and 
Modulation Index in fully vectorized forms. Included are MEX versions 
that further speed these calculations. 

Functions:

1) nf_erpac_cross:
Cross-channel event-related PAC

2) nf_erpac_within: 
Within-channel event-related PAC

3) nf_mipac_cross:
Cross-channel modulation index PAC

4) nf_mipac_within:
Within-channel modulation index PAC

5) nf_mvlpac_cross:
Cross-channel mean vector length PAC

6) nf_mvlpac_within:
Within-channel mean vector length PAC
